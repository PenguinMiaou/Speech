# Windows 本地听写计划

**目标：** 在 Windows 10/11（x64）上达到和 macOS 版相同的体验：语音识别在本机完成，只有润色文字发给用户自己配置的大模型。

**设计依据：** `docs/superpowers/specs/2026-11-09-local-first-dictation-design.md`

**现状（2026-11-10）：**

- 上游已有 Windows 的快捷键、文字输入（SendInput 和剪贴板粘贴）、应用识别、密钥保存。CI 里有 `windows-latest` 的构建任务。
- 本分支新增的部分里，这些只在 macOS 上做了：
  - 识别进程 `ot-stt-worker` 的加速（macOS 用 Metal；其他平台目前是纯 CPU 构建）。
  - 录音时静音电脑声音（Windows 上是空实现）。
  - 听写后读回输入框（Windows 上返回“不支持”）。
- 这些与平台无关，预计直接可用，但没有在 Windows 上跑过：重采样、麦克风选择和自动换麦、排版过滤、润色提示词、模型下载和校验。

## 第一台测试电脑的情况

1. 硬件：近两年的 16 核 x64 笔记本处理器，带核显，32 GB 内存，Windows 11。先测纯 CPU；不够快再试核显的 Vulkan 加速。
2. 能不能运行没有签名的安装包：未知，要把包放上去才知道。被拦的话，改为在目标电脑上从源码编译。
3. 模型下载地址可以访问。
4. 润色服务走 `chat_completions` 接口，不需要代理。地址在应用的设置里填。

## 步骤

每一步结束都要能独立验证。前一步没过，不做后一步。

### 1. 能构建、能启动

- CI 的 Windows 任务产出安装包（NSIS）和免安装压缩包，`ot-stt-worker.exe` 作为附带程序打进去。
- 识别进程先用纯 CPU 构建。
- 验证：在一台 Windows 电脑上安装、启动、打开设置页；`ot-stt-worker.exe` 能被主程序拉起并在空闲后退出。

### 2. 本地识别可用，并测出速度

- 界面一键下载模型；下载不了时，从本地文件导入，同样校验 SHA-256。
- 用仓库里的评测工具在目标电脑上跑同一批录音，记录识别耗时和准确率。
- 根据结果定默认模型：CPU 够快就用和 macOS 一样的模型；不够快，先试 Vulkan 构建，再考虑更小的模型。
- 验证：10 秒的一句话，从松开按键到出字的时间有实测数字；准确率和 macOS 上同一模型的差距有实测数字。

### 3. 录音

- 在 48 kHz、44.1 kHz、16 kHz 的设备上各录一次，确认重采样后的识别结果正常。
- 麦克风选择、没声音时自动换麦，在内置麦克风、USB 耳机、蓝牙耳机上各测一次。
- 录音时静音电脑声音：用系统的音量接口（`IAudioEndpointVolume`）实现，异常退出后下次启动恢复，和 macOS 的做法一致。
- 验证：三种设备都能录到；静音在录音结束、取消、程序被强制结束三种情况下都能恢复。

### 4. 输入到目标应用

- 在浏览器输入框、文档编辑软件、聊天软件、网页里各输入一次中英文混排的长句。
- 记录每个应用用的是哪种输入方式（SendInput 或粘贴），有没有丢字、乱序、输入法干扰。
- 验证：上面每类应用都有一条通过记录；不通过的记下应用和现象。

### 5. 读回输入框（学习修改的基础）

- 用 UI Automation 实现和 macOS 相同的接口：找到有焦点的文本控件，读全文或末尾一段，跳过密码框（`IsPassword`）。
- 先只记成败，和 macOS 的探测一样：应用、能否读到、能否找到刚插入的文字、离开前有没有变。
- 验证：在第 4 步的每类应用里听写后，日志里都有一条记录；汇总出哪些应用能学。

### 6. 密钥和设置

- 密钥存在系统的凭据管理器里（上游已有）。
- 验证：填入密钥、重启程序后还在；设置文件里没有明文密钥。

### 7. 分发

- 没有签名时，安装包会被系统拦截提示。先试安装包和免安装压缩包；都被拦就在目标电脑上从源码编译。
- 在线更新暂不做，手动换包。

## 验收

- 在目标电脑上连续用一整天：没有崩溃，没有卡住的静音，没有丢字。
- 短句（10 秒以内）从松开按键到出字不超过 3 秒。这个数字在第 2 步测完后按实际情况修订。
- 润色结果的排版和 macOS 版一致：中英文之间不加空格，几件事各占一行、不空行。

## 风险

- **纯 CPU 识别太慢。** 这是最大的不确定项，第 2 步专门用来测它。备选是 Vulkan 加速或更小的模型。
- **电脑上的安全软件拦截程序、下载或模拟按键。** 第 1 步装上去就能知道。
- **有些网页里读不回输入框。** 这只影响“从修改里学习”，不影响听写本身。
